# 回响卡

轻量记忆卡应用，支持 Markdown、HTML 沙箱预览、间隔复习与分牌组 JSON 导入导出。在线 Sites 版本将卡片和复习记录保存在 D1 数据库；直接打开本地 HTML 时仍使用浏览器本地保存。

## 在线版与迁移

在线版本默认仅站点所有者可访问。请勿在未增加账户隔离之前开放站点共享，当前数据库是所有者的一套卡片。

在旧页面选中牌组后点击下载，导出该牌组的 JSON；选择「所有卡片」时可在导出弹窗中分别下载。然后在在线版导入这些文件。旧版的浏览器存储不会自动跨网址迁移。

在线版右下角显示连接和保存状态，失败可点击重试；若其他窗口已写入，当前窗口保留本地内容并提示先导出、再刷新，避免覆盖更新。单次卡片集合限制为 8MB、10000 张。

## 运行

直接打开 `index.html`，或在此目录启动静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 快捷键

- `Space`：显示答案
- `1`：忘了
- `2`：模糊
- `3`：记得
- `4`：熟练
- `←` / `→`：上一张 / 下一张（不改变复习时间）

## 卡片与牌组

- 点击牌组查看卡片列表；点击卡片进入自由复习，包括尚未到期的卡片。编辑通过独立的「编辑」按钮进入。
- 「今日复习」只包含当前牌组已到期的卡片。只有评分会更新复习时间，同一轮中返回已评分卡片不会重复计数。
- 列表中的牌组筛选与左侧选中状态同步；新建及文件、文件夹导入跟随当前牌组。选择「所有卡片」时，文本默认进入「随手记」，JSON 保留原牌组。
- JSON 以追加方式导入，不覆盖已有卡片。重复导入会产生新的卡片副本。
- 复习左侧「目录」默认收起，展开后可切换卡片及跳转内容标题；答案标题在显示答案后出现。
- 左上角小图标收起或展开主侧边栏，状态保存在本地。
- HTML 代码块直接显示预览，支持无语言标签的 HTML 内容，源码可折叠查看。

## 开发检查

浏览器使用已随项目保存的解析器，无需联网加载。运行交互回归检查需要安装开发依赖：

```bash
npm install
node .qa/interactions.cjs
```

在答案中使用以下格式可启用 HTML 预览：

````markdown
```html
<button>一个按钮</button>
```
````
